# Cosmos data assets

Real astronomical data for the simulator. Everything here is generated by the scripts in
`tools/data/` from the original sources; `manifest.json` describes each file in machine-readable form.
Total size about 51 MB; the largest single file is 12.7 MB.

## Rebuild

    tools/data/build_all.sh /path/to/download/dir

This downloads about 800 MB of sources (each into its own subfolder), creates a Python venv with
`tools/data/requirements.txt` (numpy, pillow, h5py, tifffile, imagecodecs), and runs:

- `fetch_sources.sh` and `fetch_wms.py`: downloads only.
- `build_stars.py`: stars (standard library only).
- `build_planets.py DL_DIR data [step ...]`: maps and `manifest.json`. Steps: earth, mask, moon, mars,
  mercury, venus, galilean, saturn_moons, pluto, ceres, giants, manifest.
- `preview.py data OUT_DIR`: thumbnail sheets with the 0 meridian (red) and +90 E (cyan) marked, for checking.

Python always runs with `-I`, so it ignores the user site-packages; that is why a venv is used.
`tools/data/build_info.json` keeps build facts (JPEG quality, height ranges) between partial rebuilds.

## Stars: `stars.bin`, `stars.json`

Source: HYG database v4.4 (`hyg_v44.csv.gz`, codeberg.org/astronexus/hyg), CC BY-SA 4.0.
Selection: 0 < dist < 100000 pc, apparent mag <= 9.5, Sun removed. **91,793 stars.**

`stars.bin` is little-endian float32, 5 floats (20 bytes) per star, sorted brightest first:

| offset | field |
| --- | --- |
| 0, 1, 2 | X, Y, Z in parsecs, Sun at origin |
| 3 | absolute V magnitude (HYG `absmag`) |
| 4 | effective temperature in K |

Frame: X toward the galactic centre (l=0, b=0), Y toward the north galactic pole, Z toward l=270.
So X = d cos b cos l, Y = d sin b, Z = -d cos b sin l. Equatorial (ICRS) positions from HYG `rarad`,
`decrad`, `dist` are rotated with the Hipparcos ICRS-to-galactic matrix.

Temperature: Ballesteros (2012), T = 4600 (1/(0.92 BV + 1.7) + 1/(0.92 BV + 0.62)), clamped to
1500..60000 K; 5800 K when B-V is missing.

`stars.json`:

- `count`: number of stars in the bin.
- `named`: 1,690 entries `{i, name, hip, spect}` for every star with a proper name, a Bayer letter, or
  mag < 4. `name` is the proper name, else the Bayer designation ("Alpha1 Cen", "Gamma Ori"), else
  Flamsteed ("61 Cyg"), else "HIP n". When a star has both, `desig` holds the Bayer/Flamsteed form.
- `constellations`: 88 entries `{abbr, name, lines}`; `name` is the Latin IAU name; `lines` are
  `[i, j]` index pairs into the bin (684 segments). From Stellarium's `skycultures/modern/index.json`
  (HIP chains), mapped through HIP numbers.

Checks: Sirius l=227.23, b=-8.89, d=2.637 pc, absmag 1.45, T 10014 K. Betelgeuse T 3794 K
(HYG gives B-V = 1.50; literature B-V 1.85 would give about 3500 K, so it lands a little above the
3500 to 3700 K range). Rigil Kentaurus d=1.325 pc, Polaris b=26.5, Vega d=7.68 pc.

Gap: 6 constellation stars have no usable parallax in HYG (dist = 100000 placeholder) and are excluded,
so 11 segments are dropped: HIP 22783 (Cam), 31216 (Mon), 33165 (CMa), 54463 (Car), 89341 (Polis, Mu Sgr),
92202 (Sct).

## Planet maps: `planets/`

**Convention for every map:** equirectangular, 2:1, north up, longitude -180 at the left edge, 0 at
the horizontal centre, +180 at the right edge, east to the right (planetocentric, positive east).
Pixel (x, y) centre: lon = -180 + (x + 0.5) 360 / W, lat = 90 - (y + 0.5) 180 / H.
Checked by feature: Africa at the centre of Earth, Mare Crisium at +59 on the Moon, Olympus Mons at
-134 and Hellas at +70 on Mars, Pele at +105 on Io, Occator at -121 on Ceres, Sputnik Planitia at the
+-180 seam on Pluto, Maxwell Montes near 0 on Venus. Earth, Moon and Mars colour and height maps were
compared crop by crop and line up to the pixel (Earth: mask vs height <= 0 agree 99.3% at zero offset).

Heights are 16-bit grayscale PNG: `metres = min_m + value / 65535 * (max_m - min_m)`.

"Filled" means server no-data pixels (pure black, or pure white for Pluto and Charon) replaced by
the smoothed mean of valid pixels in the same row (rows with under 25% coverage borrow the nearest
covered row). The filled fraction is in the manifest (`nodata_filled_fraction`).

Grayscale JPEGs are single-channel; browsers upload them as RGB textures without trouble. They are
real panchromatic albedo, so a per-body tint in the shader is reasonable (for example Pluto's
reddish browns are not in the data).

USGS maps come from `https://planetarymaps.usgs.gov/cgi-bin/mapserv` GetMap requests with
`BBOX=-180,-90,180,90` in the body's planetocentric positive-east system; the exact URL per file is in
`manifest.json`.

## Not made

- Height maps for Mercury, Venus and the moons (the USGS WMS serves rendered images, not elevation
  values; the raw DEMs are multi-GB).
- An unshaded Earth colour map: Visible Earth is behind a bot check, and only the `world.topo.bathy`
  file path could be confirmed. It has relief shading baked in, so lighting from the height map will
  double up slightly.
- Pluto and Charon colour (USGS global mosaics are panchromatic).

## Milky Way: `milkyway.jpg`

Source: ESO Milky Way panorama (eso0932a, ESO/S. Brunier), CC BY 4.0. 4096x2048, galactic coordinates,
galactic centre in the middle, longitude increasing to the left. Point stars removed with 7x7 then 5x5 median
filters so they are not counted twice against the star catalogue. Built by `tools/data/build_milkyway.sh`.

## Height maps: `*_height16.png`

The 16-bit grayscale height PNGs were repacked as 8-bit RGB (R = high byte, G = low byte) by
`tools/data/pack_heights.py`, because browsers decode 16-bit PNGs to 8 bits. Decode with
`v = (R*256 + G) / 65535` and the ranges in `manifest.json`.
